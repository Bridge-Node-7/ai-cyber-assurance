# Release Validation: AI Cyber Assurance v0.2.2

AI Cyber Assurance v0.2.2 improves first-use clarity and repository validation while preserving the toolkit's defensive assurance boundaries.

## User-facing scope

The release:

- provides a clear starting point and review-path orientation;
- keeps AI assistance subordinate to accountable human decision authority;
- preserves specialist modules, synthetic examples, evidence classes, and assurance limitations;
- maintains Ubuntu and Windows GitHub Actions validation.

## Repository validation

Validation covers the regression suite, repository structure, manifest and checksum integrity, syntax, internal links, common secret and personal-information patterns, public-safety declarations, and hosted GitHub Actions.

## Security reports

Security concerns should use the private reporting path described in [`SECURITY.md`](SECURITY.md).

## Limitations

Quick Review is designed for self-guided use. Full Assurance Lifecycle remains expert-led.

Repository validation does not establish factual sufficiency of a private review, effectiveness of a real control, certification, compliance, deployment approval, or operational authorization.
