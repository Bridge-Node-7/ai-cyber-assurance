# Synthetic AI Agent Assurance Case

> **Artifact type:** COMPLETED SYNTHETIC EXAMPLE  
> **Completion status:** Complete fictional example  
> **Operational authority:** None

This example is fully synthetic and fictional. It demonstrates the Assurance Intelligence path without describing a real person, organization, system, supplier, customer, credential, vulnerability, or security finding.

## Scenario

A fictional Supplier Research AI Agent is intended to read and summarize synthetic supplier-information records.

The initial fictional condition includes:

- write authority beyond the stated read-only purpose;
- a credential without bounded expiration; and
- incomplete pre-remediation logging evidence.

The case records findings, human decision authority, corrective actions, retest evidence, and verified structural closure.

## Why this example exists

The example demonstrates:

```text
Purpose
→ Authority
→ Finding
→ Evidence
→ Human Decision
→ Corrective Action
→ Retest
→ Closure
```

It also preserves an **Unknown** pre-remediation evidence item instead of rewriting missing information as Observed or Tested.
