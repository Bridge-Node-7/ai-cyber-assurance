# Code of Conduct

## Our Standard

This project welcomes constructive, respectful, evidence-based collaboration.

Participants are expected to:

- Communicate clearly and respectfully
- Focus on defensive cybersecurity and governance
- Avoid harassment, threats, or personal attacks
- Respect privacy, ownership, and confidentiality
- Keep contributions public-safe

## Unacceptable Behavior

Unacceptable behavior includes:

- Harassment or intimidation
- Sharing sensitive or private information without permission
- Adding offensive cyber content
- Encouraging unauthorized activity
- Misrepresenting unsupported claims as proven capability

## Enforcement

Maintainers may remove comments, issues, pull requests, or contributors that violate this code of conduct.
