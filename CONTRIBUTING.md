# Contributing

Thank you for helping improve AI Cyber Defense OS.

## Contribution Principles

Contributions should improve:

- Defensive cybersecurity value
- Verification and validation quality
- Evidence clarity
- Public safety
- Operator usability
- Repeatability
- Responsible AI governance

## Accepted Contributions

Good contributions include:

- Clearer checklists
- Better evidence manifest fields
- Improved risk-register language
- Safer AI-agent governance patterns
- Secure-by-design review questions
- Public-safe examples
- Documentation improvements
- Accessibility and readability improvements

## Not Accepted

Do not contribute:

- Offensive exploit instructions
- Malware behavior
- Credential theft workflows
- Unauthorized access techniques
- Instructions for evasion, persistence, or stealth
- Sensitive operational procedures
- Private customer, employer, government, or mission data
- Proprietary third-party content without permission

## Review Standard

Every contribution should answer:

1. What defensive outcome does this improve?
2. What evidence does it help capture?
3. What decision does it help an operator make?
4. Does it preserve public safety?
5. Does it avoid overclaiming?

## Pull Request Checklist

- [ ] The contribution is defensive and public-safe.
- [ ] No secrets, credentials, tokens, or sensitive data are included.
- [ ] No offensive cyber instructions are included.
- [ ] Claims are evidence-based and appropriately scoped.
- [ ] Templates are usable by a real reviewer or operator.
