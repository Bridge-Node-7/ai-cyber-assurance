# Security Policy

## Scope

This repository contains public-safe defensive cybersecurity templates, checklists, and review workflows.

## Reporting a Security Issue

If you find a security issue in this repository, please do not disclose it publicly before maintainers have had a reasonable opportunity to review it.

Report issues through the project's GitHub Security Advisory workflow if available.

## Public-Safety Boundary

This repository must not include:

- Exploit instructions
- Malware
- Credential theft methods
- Unauthorized access procedures
- Evasion or persistence techniques
- Sensitive operational procedures
- Secrets, tokens, passwords, keys, or private infrastructure details

## Maintainer Response

Security reports should be reviewed for:

1. Public-safety impact
2. Repository integrity
3. Possible accidental disclosure
4. Needed documentation corrections
5. Whether the issue requires private handling

## Defensive Use

All materials are intended for defensive cybersecurity, governance, review, and readiness workflows.
