# Security Policy

## Scope

AI Cyber Assurance is a public defensive assurance toolkit.

## Private reporting

Do not post sensitive security details publicly.

Use GitHub private vulnerability reporting for security issues involving this repository, its validation controls, or release integrity. Provide only the minimum information needed to understand and reproduce the issue safely.

## Public release boundary

Only material deliberately approved for unrestricted public release belongs in this repository.

Repository checks support defensive governance, review, readiness, recovery, and assurance. They do not grant operational authority, certify a system, or replace context-appropriate security controls and human judgment.

## Supported version

Security and repository-integrity corrections are applied to the maintained public release.
